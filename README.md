# Heavenward ProjectCopilot AI

## Descripción

ProjectCopilot AI es un asistente corporativo basado en Inteligencia Artificial y tecnología RAG (Retrieval-Augmented Generation).

El objetivo es permitir a los colaboradores consultar documentación interna relacionada con:

- Gestión de proyectos
- Compliance
- Gestión documental
- Procedimientos operacionales

## Tecnologías

- Python
- LangChain
- Google Gemini
- FAISS
- Streamlit
- Docker
- Oracle Cloud Infrastructure (OCI)
